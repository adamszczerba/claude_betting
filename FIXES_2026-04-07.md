# Scraper Fixes Applied - April 7, 2026

## Issues Fixed

### 1. ✅ Betfair ChromeDriver Error
**Problem**: `NoSuchDriverException: Unable to obtain driver for chrome`
- Selenium was trying to auto-download ChromeDriver from the internet
- Container VPN prevented access to Google's download URLs

**Solution**:
- Added manual ChromeDriver installation in Dockerfile
- Set explicit `CHROME_BIN` environment variable
- Configured scraper to use explicit Chrome binary path

### 2. ✅ Betfair Exchange Timeout Errors
**Problem**: `TimeoutException: Timed out receiving message from renderer`
- Page refresh was timing out intermittently
- Chrome renderer not responding within 30 seconds

**Solution**:
- Added retry logic with 3 attempts
- Increased timeouts from 30s to 40s
- Fallback to full page reload if refresh fails

### 3. ✅ Bet365 ChromeDriver Error
**Problem**: Same as Betfair - `NoSuchDriverException`

**Solution**: Same ChromeDriver installation and binary path configuration

### 4. ✅ Enhanced Bet365 Logging
**Problem**: Not finding matches but no diagnostic information

**Solution**:
- Added logging for JavaScript extraction failures
- Added warning when football content detected but no matches parsed
- Better error handling in `_parse_dom()` method
